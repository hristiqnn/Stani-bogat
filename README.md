🧠 Стани богат - Училищен уеб проект

Интерактивна уеб базирана игра „Стани богат“ разработена като училищен проект с помощта на съвременни уеб технологии. Целта на играта е да тества знанията на играча с постепенно усложняващи се въпроси и парична награда.

🚀 Основни функции
- **Динамична база с въпроси:** Въпросите се зареждат последователно, като стават по-трудни.
- **Интерактивни бутони:** Бутоните за отговори сменят цвят при избиране.
- **Парична скала:** Визуализация на текущата печеливша сума и напредъка в играта.
- **Реалистичен интерфейс:** Дизайн вдъхновен от оригиналното предаване.
